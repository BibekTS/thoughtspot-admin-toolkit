Get started in three steps.

You need a ThoughtSpot login with the ADMINISTRATION privilege. Everything after the install happens in the browser.

Install

curl -LsSf https://raw.githubusercontent.com/BibekTS/thoughtspot-admin-toolkit/main/install.sh | sh
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/BibekTS/thoughtspot-admin-toolkit/main/install.ps1 | iex"

Installs into its own isolated environment. Re-run it to upgrade. Behind a corporate proxy? See the certificate fix.

Open the app

ts-admin-toolkit serve

Opens http://localhost:8080 in your browser. Keep the terminal open while you use it.

Connect your instance

Enter your ThoughtSpot URL, pick a sign-in method and click Test connection.

BasicTrusted AuthBearer token

Credentials go to your OS keychain. Then sync each section on its own; nothing forces a full sync.

What you can do.

Browse from a local cache, then act in bulk. Every sync and bulk operation runs as a tracked background job with live progress.

Bulk DeleteDelete by GUID or search, with dependency resolution.
Bulk SharingShare content to users and groups in bulk, with an impact preview.
GroupsBrowse groups, privileges, members, and who created each group. Read-only.
JobsEvery sync and bulk operation is a tracked background job with live progress.
Multi-instanceSeveral ThoughtSpot instances, each with its own cache, one picker in the sidebar.
DiagnosticsTail logs and download a support bundle with no credentials in it.

Screenshots use sample data.

How it works.

The toolkit talks to the public ThoughtSpot REST API v2 and mirrors users, groups, metadata and lineage into a local SQLite database. Browsing reads the cache. Writes go straight to ThoughtSpot.

Dry run firstEvery destructive action previews its full impact before you confirm.
TML backupDeletions are backed up to ~/.ts-admin/tml-exports/ and can be restored.
Live checkWrites are re-verified against ThoughtSpot at execution time, not against the cache.
Audit logEvery write is recorded.

Install it in one command.

Then run ts-admin-toolkit serve and connect your instance in the browser. Try it on a non-production instance first.
